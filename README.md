# Guess the Number

A simple console game written in Java: the computer picks a number and you try to guess it.

## Features

- Three difficulty levels: 1-10, 1-100, 1-1000
- "Higher" and "lower" hints
- Attempt counter and best score for the session
- Input validation
- Option to play again

## Requirements

- Java Development Kit (JDK) 8 or newer

## Run

```bash
javac GuessNumber.java
java GuessNumber
```
